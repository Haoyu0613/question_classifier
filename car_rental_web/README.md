# 极速租车 · 前端演示页面

一个纯静态的租车网站前端 Demo，无需构建工具，浏览器直接打开即可。

## 功能
- 顶部搜索栏：取车地点、取/还车时间、车型偏好（含时间校验）
- 车型筛选（经济型 / 舒适型 / SUV / 豪华型 / 新能源）
- 车辆卡片列表（座位数、变速箱、能源、日租价）
- 预订弹窗：填写姓名/手机号/租期，自动计算总价
- 响应式布局，适配手机与桌面

## 运行
直接双击 `index.html`，或起一个本地静态服务器：

```bash
cd car_rental_web
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 文件
- `index.html` — 页面结构
- `styles.css` — 样式与响应式
- `script.js` — 数据、筛选、预订交互（车辆数据为模拟数据）
